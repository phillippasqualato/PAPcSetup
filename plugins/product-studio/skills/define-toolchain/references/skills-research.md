## 3. Overlaps, conflicts and collisions

**Name collisions**
- `code-reviewer` agent exists in feature-dev, pr-review-toolkit (different content, opus), wshobson (`comprehensive-review`, `tdd-workflows`), VoltAgent, and as Jeffallan skill. Vendor one and rename (e.g. `review-bugs`), or namespace (`fd-code-reviewer`, `pr-code-reviewer`).
- `code-simplifier`: pr-review-toolkit agent vs standalone `code-simplifier` plugin in plugins-official. Pick one.
- `frontend-design`: anthropics/skills, anthropics/claude-code plugin, plugins-official plugin, and already installed here as `anthropic-skills:frontend-design`. Several local custom skills (`anti-ai-slop-design-architect`, `fintech-design-architect`, `design-tokens`, `frontend-polish`, `apple-design`) also trigger on UI work - competing descriptions will cause random selection. Keep one design-direction skill active per project.
- `design-system`: knowledge-work `design:design-system` vs ui-ux-pro-max `design-system` vs wshobson `design-system-patterns`.
- `code-review`: knowledge-work `engineering:code-review` skill vs `/code-review` plugin command.
- React perf: `react-best-practices` is already installed as `anthropic-skills:best-practice-code-by-vercel`.
- Playwright: `webapp-testing` (Python) vs `playwright-skill` (Node) vs `playwright` MCP plugin vs Jeffallan `playwright-expert` vs superpowers-chrome. Choose one skill + optionally the MCP.
- Writing: `elements-of-style`, vercel `writing-guidelines`, `design:ux-copy`, wshobson `avoid-ai-writing`.

**Two (or more) TDD / workflow methodologies**
- superpowers `test-driven-development` (hard RED-GREEN, delete pre-test code) + `subagent-driven-development` vs wshobson `tdd-workflows` (tdd-orchestrator) vs feature-dev's 7-phase flow vs knowledge-work `testing-strategy`. Superpowers brainstorming/writing-plans also overlaps feature-dev phases 1-4 and KW `product-brainstorming`. Pick one orchestrating workflow (recommend feature-dev) and at most one TDD skill.

**Hooks that force behaviour**
- superpowers: SessionStart (startup|clear|compact) injects `<EXTREMELY_IMPORTANT>` using-superpowers text into every session - effectively a system-prompt override that makes skill checks mandatory before any reply. Do not install the plugin alongside another methodology; vendor individual skills instead.
- explanatory-output-style / learning-output-style: SessionStart hooks change output style globally.
- security-guidance: SessionStart (installs Agent SDK), UserPromptSubmit, PostToolUse, Stop (LLM diff review, extra cost/latency every turn), commit-time agentic review. Worth it, but know it runs.
- impeccable: PostToolUse on every Edit/Write + Stop "Design deep pass"; downloads a binary.
- ralph-wiggum / ralph-loop: Stop hook that re-feeds the prompt (loops) - do not install by default.
- nizos/tdd-guard (from awesome list): blocks edits that are not test-first - conflicts with non-TDD flows.

**Remote / supply-chain concerns**
- `web-design-guidelines` fetches unpinned instructions from GitHub at runtime - snapshot it.
- `impeccable` downloads an executable; `ui-ux-pro-max` runs Python scripts; `security-guidance` pip-installs the Agent SDK. Review before enabling in CI.
- trailofbits `second-opinion` sends code to Codex/Gemini.
- Consider running NVIDIA/SkillSpector over anything vendored.

**Licensing**
- anthropics/claude-code repo: LICENSE.md is "All rights reserved / Commercial Terms" - vendor the same plugins from anthropics/claude-plugins-official (Apache-2.0, newer agent versions).
- anthropics/skills: per-skill LICENSE.txt; frontend-design, webapp-testing, skill-creator, mcp-builder are Apache-2.0; docx/pdf/pptx/xlsx are proprietary (not needed here).
- trailofbits/skills: CC-BY-SA-4.0 (share-alike) - install, do not vendor into closed-source repo.
- hesreallyhim/awesome-claude-code: CC BY-NC-ND - reference only.
- karpathy-guidelines: MIT stated in frontmatter/README only (no LICENSE file); elements-of-style: public domain.
- vercel-labs/agent-skills, supabase/agent-skills, shadcn-ui/ui, lackeyjb, wshobson, VoltAgent, Jeffallan, ui-ux-pro-max, superpowers: MIT. impeccable, knowledge-work-plugins, claude-plugins-official: Apache-2.0.

**Staleness**
- `vercel-labs/next-skills` is an empty redirect to `vercel/next.js/skills`; `next-best-practices` and `next-upgrade` skills were retired.
- VoltAgent and Jeffallan Next.js content targets "Next.js 14+" - outdated vs Next 16 (Cache Components, PPR).
